## Installation

If you do have Chocolatey, then that's probably the easiest way to get the Sun executable directly beamed into a directory in your path:
```
choco source add -n "Calamity, Inc." -s https://choco.calamity.gg/index.json
choco install sun
```

You can also find prebuilt binaries in [the releases](https://github.com/calamity-inc/Sun/releases), and of course you can [build it yourself](<docs/Building.md>).
